What is KeTCindy?

KeTCindy is a library for Cinderella that allows you to easily create figures for TeX.

  • Features:
    • Create interactive HTML content easily with KeTCindyJS.
    • Can utilize Maxima and gcc from KeTCindy (See Maxima/gcc Installation).
    • Easy integration of the math print macro emath (Integrated in KeTTeX2025).
    • For PC/OS related tips, see Other Operations.
